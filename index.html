필요한 것만 담았습니다.

복잡한 설정 없이 원하는 소리를 바로 사용할 수 있습니다.

01

원하는 소리 사용

MP3 또는 WAV 파일을 선택해서 자신만의 키보드 사운드로 사용할 수 있습니다.

02

낮은 지연시간

키 입력에 맞춰 소리를 빠르게 재생하도록 설계되었습니다.

03

간단한 사용법

프로그램을 실행하고 소리 파일을 선택하면 바로 사용할 수 있습니다.

사용 방법

처음 사용하는 경우에도 몇 단계만 거치면 됩니다.

STEP 01

KeySound 다운로드

다운로드 버튼을 눌러 GitHub Releases 페이지로 이동합니다.

STEP 02

프로그램 다운로드

Releases에서 최신 버전의 jeyeah.exe 파일을 찾아 다운로드합니다.

STEP 03

소리 파일 선택

jeyeah.exe를 실행한 뒤 원하는 MP3 또는 WAV 파일을 선택합니다. 이후 키보드를 누르면 선택한 소리가 재생됩니다.

지금 시작해보세요.
